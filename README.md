# Bloome

A modern Shopify theme for skincare and makeup, with an editable section library and responsive storefront layouts.

- Open preview.html for the storefront preview.
- Open preview-sections.html to explore the section library.
- Upload bloome-theme.zip through Shopify admin to install the theme.
- Read BLOOME-SETUP.md for configuration and BLOOME-SECTIONS.md for the section catalog.

Theme metadata and visual branding use Bloome. Store products, imagery, menus, policies and forms are configured in Shopify.
